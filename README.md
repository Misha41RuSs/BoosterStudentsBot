# BoosterBot

BoosterBot — это Telegram-бот, который создан, чтобы поддерживать студентов в трудные времена (например, во время сессии). Бот умеет присылать рандомные подбадривающие фразы по запросу пользователя.

## Что было сделано в Спринте 1
На этом этапе я реализовал базовый функционал бота:

* **Интеграция с Telegram API**: Бот успешно подключается через `TelegramLongPollingBot` и реагирует на входящие апдейты.
* **Работа с внешними данными**: Все фразы вынесены в отдельный JSON-файл (`compliments.json`). Бот подгружает их при старте с помощью Jackson и Jackson-databind.
* **Базовая логика**:
    - Основная команда `/compliment` выдает случайный "буст", подставляя имя пользователя.
    - Реализована обработка неизвестных команд и нетекстовых сообщений.
* **Логирование**: Настроил нормальное логирование через **SLF4J (Lombok)**. Теперь в консоли не просто каша из принтов, а структурированные логи: видно, кто зашел, что нажал и если что-то упало — сразу видна причина.



## Архитектура
Для первого этапа я выбрал простую сервисную архитектуру:
1. **Controller (BoosterBot)**: Принимает сообщения и отправляет ответы.
2. **Service (ComplimentService)**: Отвечает за логику — чтение JSON и рандомный выбор фразы.
3. **Model (ComplimentData)**: Простой POJO для маппинга JSON-файла.
