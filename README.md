# BoosterBot

BoosterBot — это Telegram-бот, который даёт студентам мотивационные и поддерживающие сообщения («бусты»), учитывая их контекст: время суток, день недели и эмоциональное состояние пользователя.

Проект построен с использованием Spring Boot и TelegramBots API, с модульной архитектурой фильтров, которые формируют конвейер обработки сообщений.

## Архитектура

Основная идея — конвейер фильтров (`Pipeline`), каждый из которых анализирует сообщение и добавляет теги (`tags`) к контексту пользователя (`ProcessContext`).

1. **ProcessContext** — хранит имя пользователя, текст сообщения, теги и результат буста.
2. **Filter** — интерфейс для всех фильтров; каждый фильтр реализует метод `execute(ProcessContext context)`.
3. **Фильтры**:
   - `WeekdayFilter` (@Order(0)) — определяет день недели и добавляет тег `weekend` для выходных.
   - `TimeOfDayFilter` (@Order(1)) — добавляет тег времени суток (`morning`, `day`, `evening`, `night`).
   - `MoodDetectorFilter` (@Order(2)) — анализирует ключевые слова в сообщении и добавляет эмоциональные теги (`sad`, `success`).
   - `UnknownMessageFilter` (@Order(3)) — обрабатывает непонятные сообщения, помечая их тегом `unknown`, если не найден эмоциональный контекст.
   - `ComplimentService` (@Order(4)) — выбирает финальный буст на основе комбинации тегов, динамически подбирая наиболее подходящую категорию.

Фильтры упорядочены с помощью аннотации `@Order`, что позволяет строго управлять последовательностью обработки и легко расширять логику бота.

## Динамический выбор буста

Бот комбинирует теги для выбора наиболее подходящего ответа. В отличие от жестких условий, здесь реализован алгоритм **Best Match**:

* Бот анализирует всё накопленное множество тегов в контексте.
* `ComplimentService` ищет в `compliments.json` ключ, который максимально полно соответствует текущему набору тегов (например, `evening_sad` или `weekend_success`).
* Выбирается категория с наибольшим количеством совпадений.

Это позволяет создавать персонализированные ответы, которые выглядят как живое и внимательное взаимодействие с пользователем.

## Использование

1. Настроить `application.properties`:
   ```properties
   bot.name=BoosterBot
   bot.token=YOUR_TELEGRAM_BOT_TOKEN
2. Запустить Spring Boot приложение:
   ```bash
   mvn spring-boot:run
